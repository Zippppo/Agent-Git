# Changelog

All notable changes to Agent-Git will be documented in this file.

This project uses a lightweight changelog format while it is pre-1.0.

## Unreleased

- Documented open source contribution, security, privacy, and development
  workflow expectations.
- Added GitHub Actions automation for Windows release artifacts.
- Added Windows app icon assets and release artifact naming.
- Added README hero artwork, product screenshot, release badges, and Windows
  download guidance.

## 0.1.0 - 2026-06-10

- Migrated the original single-file prototype into a Vite and Electron desktop
  app.
- Added daily task snapshots, task roots, checkpoints, `HEAD`, fork actions,
  status changes, local persistence, JSON export, and image attachments.
- Added basic zoom shortcut tests.
